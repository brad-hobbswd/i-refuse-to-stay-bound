Instructor Access Information

The instructor resource collection includes the instructor guide, weekly answer key, and 12 week lesson plans. These materials are intended for leaders facilitating the study.

Access status: Secure password protection is not active yet.

GitHub Pages does not provide server-side password protection for individual pages or PDFs. A password form on this static site would not prevent direct access to files stored in this public repository.

To keep instructor materials restricted, they must be stored in a private file service with access permissions enabled. Once that is configured, this page can direct approved instructors to the protected materials.
