# I Refuse to Stay Bound

**Overcoming Offense, Releasing Bitterness, and Walking in the Freedom of Jesus Christ**  
By Bradley Hobbs

The official website for this Christian book project, exploring offense, bitterness, forgiveness, and the freedom found in Jesus Christ.

## Website

- Live site: https://brad-hobbswd.github.io/i-refuse-to-stay-bound/
- Repository: https://github.com/brad-hobbswd/i-refuse-to-stay-bound

## About

The website introduces the heart behind the book, its message, the author, and publication updates. Teaching, reflections, prayers, affirmations, and practical application are woven into the chapters themselves.

The book is original work by Bradley Hobbs. *The Bait of Satan* by John Bevere is acknowledged as an inspiration for further reflection on offense and forgiveness, not as the source text for this book.

## Website Pages

- `index.html` — Homepage and introduction

## View Locally

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in a browser.

When making updates, preserve the burgundy, gold, and cream theme. Check that links, image paths, and navigation work on desktop, tablet, and mobile devices.
